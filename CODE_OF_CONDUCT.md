# Code of Conduct

Short version: be decent. Long version:

## The rules

- Be respectful. Disagree with ideas, not people.
- No harassment, hate speech, or personal attacks — in issues, PRs, or anywhere else.
- No spam, no self-promo that isn't relevant to the project.
- Assume good intent; text is a terrible medium for tone.
- New contributors get patience, not pile-ons.

## Enforcement

Maintainers may remove content and block users who break these rules.
Report issues to the maintainer via GitHub (@AbhiAva) or a private issue.

This is a prototype of a code of conduct, not a legal document. If a situation
needs more structure, we'll adopt the Contributor Covenant wholesale.
